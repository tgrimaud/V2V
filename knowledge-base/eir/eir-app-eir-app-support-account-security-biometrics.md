# Biometric (Face ID or Fingerprint log in)

**What is biometric login?**

A biometric login uses a person's unique characteristics, such as fingerprints or facial recognition, to verify their identity when logging into an app or device.

Setting up Face ID or fingerprint login for the eir app ensures a faster and more secure login without the need to remember tricky passwords.

**How to enable biometric login in the eir app?**

When you log into the eir app for the first time, you will be asked to enter the verification code that will be sent to your phone. You will then be given the option to set-up your biometric login (Face ID or fingerprint).

**Please note:** you will need to have face ID or fingerprint enabled on your device in order to set it up on the eir app.

**How to disable biometric login in the eir app?**

You can turn off face ID or fingerprint at any time in the eir app by following the steps below:

1. Open the eir app and login.
2. Navigate to the menu button in the top right-hand corner.
3. Select 'Preferences'.
4. You can turn off Face ID or fingerprint using the toggle.
