# eir mobile security

**What is eir mobile security?**

eir mobile security is a mobile security application that protects mobile users of both Android and iOS devices, from online attacks, viruses, spyware and all potential sources of threads and data misuse.

**How to set up eir mobile security app**

**1\. Download the app**

After receiving your welcome SMS or email, tap the link provided to go directly to the correct app store:

- [Google Play Store (Android)](https://play.google.com/store/apps/details?id=ie.eir.mobilesecurity&hl=en_IE&pli=1 "Google Play Store (Android)")
- [Apple App Store (iOS)](https://apps.apple.com/ie/app/eir-mobile-security/id6464393717 "Apple App Store (iOS)")

Alternatively, you can search for "eir Mobile Security" in your app store manually.

**2.Install the app**

Tap Install and wait for the app to download and install on your device.

**3.Enter your mobile number**

Open the app and enter the mobile number you used to sign up for the service.

**4\. Verification code**

You’ll receive a verification code via SMS sent to the number you entered. Please enter the verification code into the app to proceed.

**5\. Initial device scan**

The app will automatically activate and begin an initial scan of your device to check for any existing threats.

**6\. Enable advanced phishing protection**

For enhanced protection, we recommend enabling Advanced Phishing Protection.

**How can I enable the Advanced Phishing Protection?**

You can find instructions for enabling the Advance Phishing Protection on the below links:

1. [Enable Advanced Phishing Protection for iOS devices](https://eir.ie/enable-advanced-phishing-protection-for-ios/ "Enable Advanced Phishing Protection for iOS devices ")
2. [Enable Advanced Phishing Protection for Android devices](https://www.eir.ie/enable-advanced-phishing-protection-for-android/ "Enable Advanced Phishing Protection for Android devices")

**Is eir mobile security compatible with any mobile device?**

eir mobile security is compatible with all iOS and Android devices.
