### How can I improve my speed?

**How can I improve my broadband speed?**

- [Run a speed test](https://www.eir.ie/helpandsupport/broadbandspeedtest/) on a laptop or a PC connected to your router with an yellow or white ethernet cable to see if you are getting full speed or not.
- Remove all other devices accessing the WiFi network and cable connections to ensure you are getting a true speed result.
- If you are getting the full speed with one device connected via cable, it's likely to be an issue with the WiFi connection.
- If you are using third party networking devices, please refer to the manufacturers documentation.

**Slow broadband speed when using a cable connection**

If your broadband speed is slow on a cable connection, follow these steps:

- Restart your router.
- Check the speed on other devices if possible as this will determine if you have an issue with the broadband speed or the device itself.
- Ensure you are using Cat 6 ethernet cables for both the connection between the fibre box 7 & ONT (Optical Network Terminal) and the fibre box 7 & wired device.
- Ensure the device you are using is capable of 2Gb speeds.

**If you experience slow speed on your computer**

If you experience slow speed on your computer try:

- Clearing the browser's history and cookies.
- Stopping any automatic updates on your device.
- Make sure that you are using the latest version of the internest browser you use.
- If this still does not work try using a different internet browser.

- Make sure that if you have antivirus software that it is up to date.
- Ensure you are using Cat 6 ethernet cables for both the connection between the fibre box 7 & ONT (Optical Network Terminal) and the fireb box 7 & wired device.
- Ensure the device you are using is capable of 2Gb speeds.

If you are not getting close to full speed with a wired cable connection on multiple devices, get in touch with our broadband support team by calling **1901**.
